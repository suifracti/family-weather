# 手机独立字幕与准备链路

当前候选沿用 sv4／60210 的 SenseVoice 处理链，摘要派生方法为结构化 V6（沿用 V5 事实与回看绑定）。手机默认使用固定 SenseVoice int8 + sherpa-onnx，识别明确失败后保留用户主动选择的 Vosk 回退。无需电脑服务，不默认调用大语言模型。

节目真实日期、来源 URL、媒体 SHA、模型及处理链身份参与制品校验与缓存隔离。准备任务共享媒体与同一任务，保留租约保护、安全取消及取消后重新准备。整合与清理不改变这些约束，不清空偏好、字幕缓存或手动资料。

## 实际结果及未验范围

固定交接中的 Windows sv4 原始结果为 45 cue／882 词。2026-10-06 在 Mac ARM64 模拟器实际完成 2026-10-02、id 24222 节目的下载、完整准备和 SenseVoice 推理，得到 45 cue／875 词；confidence 未知保持 null。两个系统的 PCM 哈希不同，不能假定转写完全一致。城市报数仍有错误，**内容质量未通过**。历史 x86 MuMu＋ARM 转译性能不能当作 Mac／真 ARM 手机性能。

V5 先按句界限制时间绑定，合并同一事件的多地区断言，再选择最多六条不同变化。每个断言保留字面地区、时间、天气、可选注意事项及来源 span；一条事件共享连续字幕的回看范围。缺字段不补猜，后续城市报数不能借用前段时间。升级只重建旧摘要，ASR 和媒体缓存身份不变；覆盖旧派生制品前将完整旧制品保存到应用私有 `files/local-summary-history`，不作为缓存命中来源。

对同一解码 PCM、同一模型做了七个有限窗口对照：精确采样起点重现原城市窗口；城市短窗恢复部分机器假说，但风雨短窗新增“不会飘落雪花”的否定错误，生产分窗未改变。窗口边界、重叠、时间映射和修前修后制品在项目外私有验收目录留存。

Mac 已恢复依赖、完成 ARM64 构建、原生库加载及播放。V6 使用自然短句，待核与原句默认折叠；保留 V5 事实绑定及回看。摘要表达改进不代表完整转写准确率通过。

截至2026-10-07，人工已核三段：哈尔滨多云4–15℃；还会有大雨、局地可能会飘落雪花；假期后半段五号到七号、福州／南宁下半年首次最低低于20℃。只有这些范围可用于已核回归，不能扩大为整片真值。生产哈尔滨仍漏字段，福州／南宁有图上→涂上字错；雪花原生产短句关系正确，旧裁切新增否定为实质错误。其余雨种、温度、地区归属、精确词时及整体WER/CER仍未核。有限短窗有收益也有退化，生产分窗不变，不继续要求用户听核。

**暂停开发，保留未来继续。** 本次不补跑准备／推理，不修改ASR或摘要。真实跨午夜／断网／ETag／存储和低内存边界仍有未验部分；天气功能封存不代表ASR缺口已解决。
