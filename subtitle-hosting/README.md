# 字幕文件归档

原 `suifracti/weather-subtitles` 仓库的文件及全部提交历史已合并到此目录，后续维护集中在私有 `suifracti/family-weather` 仓库。

- `subtitles/` 保留原字幕索引、节目清单和 VTT 文件，未修改其内容。
- 原仓库归档后仅作为旧版本兼容入口，不再用于日常开发。
- 当前 App 的字幕地址由本地 `breezy.subtitle_base_url` 配置，使用腾讯云 COS；合并目录不会自动发布或改变 App 下载地址。
- 本地配置和凭据不提交到仓库。现有字幕生成、发布工具仍位于 `tools/asr/`。

原入口：https://suifracti.github.io/weather-subtitles/
